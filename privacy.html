Privacy Policy - Jarvis Life OS

Last updated: September 25, 2026

1. About the app

Jarvis Life OS is a personal, non-commercial productivity application. It is not offered to the public and is used only by its developer. Contact: atraquia@gmail.com.

2. Data accessed

With the user's explicit consent through Google OAuth, the app accesses files and file metadata (names, folders, dates) in the user's Google Drive. The app does not access any other Google account data.

3. How data is used

Drive data is used only to provide the app's features to the user who authorized it: reading, organizing, summarizing and creating files at the user's request.

When the user requests it, the content of specific files may be sent to a third-party AI provider's API (such as Anthropic) solely to process that request and return the result to the user.

4. Storage

OAuth tokens and processed data are stored locally on the user's own computer. The app does not operate its own servers and does not keep copies of Drive data elsewhere.

5. Sharing

Google user data is not sold, not used for advertising, and not shared with anyone except the AI provider described in section 3, only to fulfill the user's request.

The app does not use Google user data to develop, improve or train generalized AI or machine learning models.

6. Limited Use

Jarvis Life OS's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token files removes all stored authorization. Deletion requests can be sent to the contact email above.
